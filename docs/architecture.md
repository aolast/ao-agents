# 架构与边界

## 单仓库，按职责组织

使用 private GitHub repo。Agents 相关资产集中在 `agents/`，仓库维护脚本在 `scripts/`，个人工作流在 `workflows/`，文档与知识统一在 `docs/`。人类与 Agents 的共同开发流程以根目录 `DEVELOPING.md` 为准。

本仓库同时保存经验和可执行资产。知识笔记解释“为什么、在什么条件下有效”；指令和配置定义“希望如何运行”；代码落实需要程序执行的行为。三者可以互相引用，但不自动互相生效。

按资产职责组织顶层目录，只在 `agents/configs/` 等确实依赖软件的边界下按工具分组。暂不建立统一配置语言、通用 Agent 执行器或统一构建系统。

## 指令与能力

`agents/prompts/fragments/` 保存多个指令确实需要复用的规则片段。`agents/prompts/managed/`、`agents/prompts/user/` 和 `agents/prompts/project/` 分别保存对应目标层的源文件或模板。

这些分类表达部署意图，不声明任何软件的加载优先级或对 managed 指令的支持。实际名称、路径、权限和覆盖语义必须在对应工具的配置说明中核实。

`agents/prompts/tasks/` 保存可以直接粘贴使用的任务入口。需要明确触发条件、可复用步骤和配套资源时，使用 `agents/skills/`。零散 skills 直接放在该目录，数量和职责需要时再分组。软件开发采用 `ao-sdlc-` 命名空间，在活动分类目录下放独立的 skill 文件夹，根据各 skill 的名称和描述选择能力。各活动可相互组合，不构成强制调用层级。分类与 skill 入口统一见 [Skills 目录](../agents/skills/README.md)。

规则只维护一份。编排 skill 负责步骤、依赖、输入输出和停止条件，引用基础 skill 的标准。分发时必须确保被引用的依赖也已安装；不假定目标工具能访问仓库里的相对路径。

## Plugins 与配置

`agents/plugins/<name>/` 保存目标工具要求的包装和清单。共享 skills 的源仍在 `agents/skills/`；插件专属且不共享的资产可以放在插件内部。每个资产只有一个维护源。

如果目标插件要求内嵌文件，打包时从维护源复制到忽略的 `dist/`；避免手工维护两份。具体打包方式在首个插件落地时决定。

`agents/configs/<tool>/` 使用原生格式组织权限、模型、插件、hooks 等设置。这些设置通常属于同一个原生文件，不为分类而强制拆文件。环境差异只在真实出现时引入覆盖文件，并写明合并方式。

## 代码与工作流

- `agents/hooks/`：由 Agent 工具事件触发的程序。触发注册放在对应 `agents/configs/<tool>/`，行为实现在这里。
- `scripts/`：用户或维护过程直接调用的工具。hook 的启动包装可跟随 hook 放置，不为扩展名拆开同一组件。
- `workflows/<name>/`：围绕某个目标组合 prompts、skills 和程序。工作流专属代码就近放置；出现真实复用后再提取。

Agent hooks 统一使用 Rust 开发，以便分发独立二进制。Git hooks 是仓库维护脚本，放在 `scripts/git-hooks/`。初期一个实际需要的 crate 即可，出现多个共享构建需求的 crates 后再建立 Cargo workspace。输入输出格式、超时和失败行为按宿主工具分别适配。

## Workflows 与 services

当前保留 `workflows/`：它表示围绕一个目标组织的步骤，可以手动、定时或按事件触发。触发方式不改变工作流的职责。

`services/` 适合长期运行、需要启动停止、健康检查和部署管理的独立程序。将来出现这种实际需求时再建立。工作流可以调用服务；服务也可以承载多个工作流，两者按职责区分。

## 从维护源到运行环境

流程是：编辑维护源 → 做针对性验证 → 必要时打包 → 查看安装差异 → 安装到明确目标 → 检查实际加载结果。

源文件、生成的分发文件和机器运行状态分开管理。由维护源自动生成的仓库阅读目录随源代码提交。分发与构建产物进入 `dist/` 或 `build/`；安装记录、备份和本机覆盖进入 `.local/` 或工具本地状态目录，两类内容均不提交 Git。

安装器的最小要求是：显式源与目标、预览、重复运行不产生额外变化、冲突检测、保留原文件及恢复方法。不得整目录覆盖用户现有配置。卸载只能处理本次安装管理的内容，不能删除后来由用户修改的文件。
