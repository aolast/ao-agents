# Skills 目录

本目录统一索引可复用 skills。零散 skill 直接放在此目录；`software-development/` 按开发活动分组，各分类下放具体 skill 文件夹。

`communication/` 按表达职责组织，包含通用表达原则与具体产物的写作方法。Commit message 和设计文档的写作方法归入该分类；形成设计与作出方案取舍归入 `design/`，具体实现方法归入 `implementation/`。
