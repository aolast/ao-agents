# Agent Entry

This is the agent entry point for working in Ao Agents.

1. Read `README.md` for repository purpose and layout.
2. Read and follow `DEVELOPING.md`, the shared development and maintenance process for both humans and agents.
3. Read the relevant component README. Consult `docs/architecture.md` when deciding boundaries or file placement.
4. Select relevant skills from their available names and descriptions. Load only what the task needs.

Keep shared development rules in `DEVELOPING.md`; do not duplicate them here. Distributable prompts and instructions belong in `agents/prompts/`.

`CLAUDE.md` must remain a symbolic link to `AGENTS.md`, not a separately maintained copy.
